# Agent kit: indic-stt

Files for building the open-source Indic STT engine with coding agents, one module per session.

- `DECISIONS.md`: fill this in first
- `PLAN.md`: constraints, waves, modules, how to run
- `CLAUDE.md`: standing rules every agent session follows
- `docs/architecture.md`: the full specification (pipeline, contracts, compression, targets)
- `modules/`: one brief per module (A01–A27)
- `STATUS.md`: tracker the agents update

Start: copy this folder into an empty repository (module A01 does the rest), fill in DECISIONS.md, then open a session with:

> Read CLAUDE.md and PLAN.md, then do modules/A01-repo-scaffold.md.
